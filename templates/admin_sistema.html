Herramientas principales

Estas acciones están separadas en bloques para que controles el sistema sin afectar el resto.

📦 Crear respaldo liviano

Genera un archivo ZIP compacto con la información esencial para recuperar tu operación y subirla a Render.

🗓️ Guardar cierre por fecha

Congela cómo terminó el día: sorteo, juego, ventas, impresión y demás data de esa fecha.

Consejo: hazlo al terminar cada jornada para poder consultar exactamente cómo cerró el día.

♻️ Reiniciar sistema a 0

Deja la data operativa en blanco para comenzar desde cero. Mantiene usuarios para no sacarte del sistema.

Haz respaldo antes de usar esta opción.
Si tus rutas aún no están conectadas en app.py, este HTML se verá bien pero los botones no ejecutarán nada hasta enlazar /admin/backup, /admin/cierre y /admin/reset.
